# RHYNO EV – Electric Vehicle Website

## About the Project

RHYNO EV is a modern and responsive electric vehicle website developed using React.js. The project focuses on presenting electric vehicles through a clean, attractive, and user-friendly interface.

The website provides information about electric vehicles, vehicle comparisons, and enquiry options, offering users an engaging browsing experience.

## Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Bootstrap
- Vite

## Features

- Modern and responsive user interface
- Electric vehicle showcase
- Attractive homepage and banner section
- Vehicle comparison section
- Enquiry form
- Test-drive booking interface
- Book Now functionality
- Admin login interface
- Responsive design for different screen sizes

## Installation and Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd ryno-react
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in browser**

Open the local URL displayed in your terminal (usually http://localhost:5173).
